Methodology notes

Business metrics exclude authentication and warm-up traffic. Profile p95 thresholds come from runtime GitHub variables when configured, otherwise the documented fallback is used. Optional endpoint-specific p95 gates come from K6_ENDPOINT_P95_THRESHOLDS_JSON, allowing Jira Issues to have a justified target without weakening fast core routes.

Threshold failures remain valid evidence: reports are written before k6 exits non-zero, and the Azure/Gateway restoration path still runs.
